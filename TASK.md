Тестовое задание

Задача

Реализовать сервис, предоставляющий API по созданию и изменению задач.

Сервис должен быть написан на Go и принимать следующие запросы по http:

Метод Get, который будет возвращать список всех существующих задач.

Метод Post, который будет логинить пользователя.

Метод Post, который будет разлогинивать пользователя.

Метод Post, который будет регистрировать пользователя в базе.

Метод Get, который будет возвращать список задач, порученных конкретному пользователю.

Метод Get, который будет возвращать список задач, созданных конкретным пользователем.

Метод Post, который будет сохранять информацию о новой задаче в базе (создание задачи).

Метод Post, который будет сохранять информацию о задаче в базе (назначить задачу на кого-то).

Метод Post, который будет сохранять информацию о задаче в базе (снять задачу с кого-то).

Метод Post, который будет сохранять информацию о задаче в базе (пользователь выполнил задачу).

Решение должно соответствовать условиям:

— Сервис распространён в виде Docker-образа;

— В качестве хранилища пользователей MongoDB;

— В качестве хранилища задач MySQL;

— В качестве хранилища сессий Redis;

— Простой frontend для взаимодействия с API;

— Аутентификация при помощи Cookie;
